# This asset folder is not distributed with this repository

The files normally found here come from the third-party **Bloodlines —
Dark UI** GUI kit by xGaida and Shieldomirs. Its licence permits use inside
an integrated project (like this game) but **does not allow the raw files
to be redistributed from a public repository**, so they are excluded
(this folder's contents are gitignored; only this README is tracked).

See `THIRD_PARTY_ASSETS.md` at the repository root for details, and the
pack's own `LICENSE.txt` for the full terms (kept locally, not committed).

**To run the game from source:** obtain the pack yourself and copy its
contents into this folder, matching the original file layout. The game
will not render its UI correctly without them.
